# ひとあみ — 編み物サポート MVP

写真相談から、ひと工程ずつ制作を進める個人用Webアプリです。

## 実装内容

- スマホ対応トップページ、作品一覧・7カテゴリー、お気に入り一覧。
- JPEG / PNG / WebPの写真選択・ドラッグ＆ドロップ（10MBまで）。長辺1000pxのJPEGに縮小し、保存容量を抑えます。
- モックの相談結果：想定される特徴、道具と用途、材料・量の目安、複数の技法候補と推奨理由。
- サイズ入力、円周の目安、写真つき制作ノートの保存。
- 1工程ずつ表示するSTEP画面、完了・取り消し、最初の未完了工程から再開。
- ランプカバー、コースター、ミニマフラー、ポーチの4サンプル。
- 糸・針の持ち方、作り目、鎖編み、細編み、中長編み、長編み、引き抜き編み、増し目、減らし目、ネット編み、方眼編み、糸始末の13項目。
- 日本語の参考動画への外部リンク、再生速度の案内、端末ごとの参考URL変更。
- 保存失敗・不正画像・不正URL・空一覧・存在しない画面への対応。

## 起動方法

Node.js 22以降で、プロジェクトフォルダを開き、以下を実行してください。外部パッケージのインストールやビルドは不要です。

```sh
node server.mjs
```

表示された `http://127.0.0.1:4173` をブラウザで開きます。終了はCtrl+Cです。`index.html`をダブルクリックする方法では、ES Modulesを読み込めないためHTTPサーバーを使ってください。

サイトの公開先は個人専用のSitesです。ローカル環境と公開URLは別の保存領域を持ちます。

## 使用技術・ファイル構成

追加依存なしのHTML / CSS / JavaScript ES Modules、localStorage、Canvas、Node.js標準HTTPサーバー、Sitesの静的ホスティングを使用しています。

```text
hitoami/
  dist/
    index.html          ページの枠・メタデータ・アイコン
    style.css           レスポンシブデザイン
    app.js              画面・ハッシュルーティング・イベント
    data.js             作品・技法・動画・道具の編集可能なデータ
    analysis-service.js AI差し替え境界・モック・画像読み込み
    store.js            保存・進捗・サイズ案内・URL検証
    assets/lamp.png     AI生成の参考イメージ
  tests/core.test.mjs    データ整合性・保存・モック等の検証
  server.mjs            ローカル起動用サーバー
  package.json          起動・検証コマンド
  .env.example          将来のサーバー用設定例（現在は未使用）
  .openai/hosting.json  Sites設定
```

## AIはモックです

画像の内容を実際に解析しません。ユーザーが選択したサンプル作品のデータを返します。写真を外部送信せず、モックであることをアップロード画面・結果・保存後の作品で明記しています。生成画像も実際の編み図や完成品ではありません。

`analysis-service.js`の`analyzePhoto(input, { adapter })`が差し替え境界です。本番化時はサーバーの認証済み画像解析エンドポイントを呼ぶadapterを実装し、結果のスキーマ検証、サイズ制限、エラー処理、推測表現の検証を追加します。現在の結果画面はテンプレートIDを使うモック向けであり、自由なAI結果には画面と保存モデルの拡張も必要です。

APIキーをブラウザコードや`dist/`に置いてはいけません。将来のサーバー側で環境変数 `OPENAI_API_KEY` を使用します。`.env.example`は将来用の例で、現状の静的アプリは環境変数を読み込みません。キーを設定するだけで本番AIになるわけではありません。

## 作品の追加

`dist/data.js`の`projects`配列に追加します。既存の作品をひな形に、重複しない`id`、`name`、`short`、`categories`、`difficulty`、`description`、`materials`、`dimensions`、`techniques`、`steps`を指定してください。

画像は`dist/assets/`に置き、`image: 'assets/filename.jpg'`と説明の`imageNote`を追加します。画像を省略した作品は文字の見出しになります。

各STEPは`id`、`title`、`description`、`techniques`、`tip`、`videos`を持ちます。進捗は作品IDとSTEP IDで保存するため、公開後に同じ内容のIDを変更しないでください。サンプルは`sample: true`にします。

## 編み方の追加

`dist/data.js`の`techniques`に追加します。`id`、`name`、`group`、`summary`、`use`、`steps`（文字列配列）、`mistakes`、`videos`を指定してください。辞典の項目・カテゴリーは自動表示されます。作品やSTEPの`techniques`から、そのIDを参照します。

## 動画URLの追加・変更

共通データは`dist/data.js`の`videoResources`を編集します。`title`、`url`、`provider`、`language`、`kind`、`duration`を指定し、技法やSTEPの`videos`にIDを追加します。`kind`は将来の短い動画・生成動画を区別するため拡張可能です。現在の描画は外部リンクのみ対応です。

個人用には「編み方辞典 → 参考動画を管理」で既存項目のURLを差し替えできます。YouTubeとクロバーのHTTPS URLのみ受け付けます。別ドメインを許可する場合は`store.js`の`validVideoURL`も変更してください。

- https://clover.co.jp/movie/kagibari_kiso2 （細編み）

専用動画が未登録の技法は基礎一覧、または関連する基本技法へ案内します。外部動画のダウンロード・再配布や独自の埋め込みはしていません。動画の設定で利用可能な速度を選んでもらう方式です。

## 保存と制限

- 保存はこのブラウザ・このURLのlocalStorageのみ。ログインや端末間同期はありません。ブラウザデータ削除やプライベートモード終了で失われる場合があります。
- 写真も縮小してlocalStorageに保存します。多くの写真を登録すると容量に達します。保存失敗は画面に通知し、保存済みとは表示しません。写真一覧の削除・エクスポートは未実装です。
- JPEG / PNG / WebPに対応。HEICはJPEGへの変換が必要です。
- STEPは初心者が流れを試せるサンプル。完全な編み図、確定目数・段数、正確な材料量は提供しません。
- サイズは幅・直径・高さと円周の案内に利用します。ゲージに基づく目数計算や材料量の自動調整は未実装です。
- ランプカバーの取り付け・耐熱性は未検証。練習用編み地として扱い、照明への装着はメーカー指示を確認してください。
- オフライン専用アプリではありません。外部動画を見るにはネット接続が必要です。
- 新しい動画を画面から独立項目として追加する機能は未実装です。既存URLの差し替えは可能で、追加はデータファイルで行います。

## 検証

```sh
node --test tests/core.test.mjs
```

6件の検証：作品と技法・動画の参照整合性、進捗の保存と復元・再開・取り消し、破損データと保存失敗、モック明示、AI adapter境界、サイズ案内・URL許可リスト。

ブラウザ検証の結果は `VALIDATION.md` を参照してください。

## 次に実装するもの

1. 編み物経験者によるサンプル手順と完成レシピの確認。
2. サーバー側の画像解析、構造化出力の検証、写真ごとの推測と不確実性の表示。
3. ゲージ入力、編み図に合わせた目数計算、材料量の調整。
4. 写真・作品の削除、バックアップ／復元、必要なら端末間同期。
5. 技法ごとに、より短く手元の動きが分かる日本語動画を充実。
6. 完成写真と制作履歴、STEP単位の質問機能。

## スマホ操作の改善（2026-09-24）

- 作品ページの開始／再開ボタンを画面下に固定。
- 制作中は下部ナビを工程専用操作に切り替え。「できた、次へ」で保存と移動を一度に実行。
- 道具・材料、参考動画、STEPの補助説明は開閉式にしてスクロールを短縮。
- タップ領域、本文と入力欄の文字、写真選択の導線を調整。
- ホームインジケーターの余白に対応。ズームを禁止せず、端末の文字拡大を尊重。
- 写真相談から戻ったときのサンプル・サイズ入力を保持。
- 状態更新時に開いていた補助説明とキーボードフォーカスを保持。
